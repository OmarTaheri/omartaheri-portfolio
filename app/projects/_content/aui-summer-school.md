## Overview

This is the public website for Al Akhawayn University's 2026 Summer School on **Industry 4.0 and Smart Manufacturing**, built for the School of Science & Engineering in Ifrane.

The goal was straightforward: give the program one clear, responsive place where a prospective attendee can understand what is happening, who is teaching, who is involved, and how to register.

## What I built

- A responsive event landing page.
- Program and topic overviews.
- Instructor and partner sections.
- Venue information and a clear registration call to action.
- Mobile navigation and a visual system based on AUI's colors.
- A lightweight static site with no build step or application runtime.

## Built with

- Semantic HTML
- Custom CSS
- JavaScript
- Responsive design
- Keyboard navigation and accessibility-minded content structure

## Keeping it useful

Event websites live or die by their details. Dates, contacts, instructor names, partner information, and registration links need to remain easy to verify and update. The deliberately simple technical foundation keeps that maintenance close to the content.

## Current status

The 2026 program site is published as a complete single-page experience. Future cleanup can separate its styles and scripts, add richer social previews, and automate accessibility and Lighthouse checks.
