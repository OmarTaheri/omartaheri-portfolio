## Overview

This portfolio is a personal site presented as a deck of collectible cards. It brings my background, projects, current work, and contact details into one playful interface.

## What I built

- A responsive card-based layout with light and dark themes.
- Movable cards and stickers with keyboard, mouse, and touch support.
- A project collection backed by one Markdown note per project.
- A Cloudflare-compatible application build.

## Technologies

- Next.js
- React
- TypeScript
- CSS
- Cloudflare Workers

## Design direction

The visual language combines ink, parchment, ornate borders, and personal stickers. The goal is to make the portfolio feel collected and handled instead of arranged like a generic template.

Live and evolving. The page you are reading is part of the project itself.
