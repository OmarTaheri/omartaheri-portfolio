## Overview

mycv is a personal website shaped like a curriculum vitae. It is a compact experiment in turning familiar résumé information into a browsable web page.

## What I explored

- Organizing experience and skills for quick scanning.
- Giving a conventional CV a more personal presentation.
- Keeping the project small, direct, and easy to maintain.

## Technologies

- HTML
- CSS
- Personal web design
