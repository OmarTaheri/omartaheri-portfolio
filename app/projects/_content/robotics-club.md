## Overview

Robotics Club is the web home of Al Akhawayn University’s Robotics Club. I built it and keep it running on self-hosted infrastructure.

## What I worked on

- A public home for the club and its activities.
- Deployment and day-to-day operation on self-hosted infrastructure.
- A web presence the club can continue to use as its work evolves.

## Technologies

- Web application development
- Self-hosting
- Server operations
