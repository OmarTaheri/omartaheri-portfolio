## Overview

backblaze-site-backup is a Python utility for automating website backups through the Backblaze API.

## What it solves

Manual backup routines are easy to postpone and hard to repeat consistently. This utility turns that recurring maintenance task into a scriptable workflow that can be run as part of normal site operations.

## Technologies

- Python
- Backblaze API
- Backup automation
